# ECG Strip Interpretation

## 5 Steps
1. Heart rate (60-100 normal)
2. Rhythm (regular/irregular)
3. P wave (present before each QRS?)
4. PR interval (0.12-0.20 sec)
5. QRS complex (<0.12 sec)

## Key Rhythms
- NSR: 60-100, regular, P before QRS
- AF: irregularly irregular, no P waves
- VT: wide QRS, rate >100
- VF: chaotic, no QRS, DEFIB immediately
- Asystole: flat line, NOT shockable

## Heart Blocks
1st degree: prolonged PR. 2nd Type I: progressive lengthening. 2nd Type II: dropped QRS. 3rd: complete dissociation.
