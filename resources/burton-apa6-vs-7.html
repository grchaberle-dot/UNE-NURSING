Ch 7 Logic That Still Works

  • Cite quotes AND paraphrases; not citing = plagiarism
  • Prefer refereed journals
  • Narrative: Senior (2010) · Parenthetical: (Senior, 2010) · "and" outside, "&" inside
  • Multiple in one bracket: alphabetical, semicolons · same author: chronological · same year: 2009a, 2009b
  • Quotes need page (p. 74) or para.; 40+ words = block quote, citation after full stop
  • Latin abbreviations (e.g., i.e., cf.) only in brackets, except et al.
  • Secondary: (Original, 2002, as cited in Read, 2015). List only what you read
  • Personal communication: in-text only

Ch 8 + Ch 1 Essentials

  • Reference list = only works cited (not a bibliography); take details from the original
  • Order: alphabetical → same author oldest first → single author before multi-author
  • Essay = review of past literature, no own data; intro → body → conclusion
  • Quantitative = numbers, large samples, stats · Qualitative = themes, small samples, participant perspective
  • Past 5 years + key earlier works; compare old vs new
