## What is this?

Interactive study hub for UNE's Bachelor of Nursing (BNURS, Rule A). Everything lives here: learn cards, practice exercises, quizzes, reference materials, and session resources.

## Structure

```
/                    → index.html (main hub page)
/HLTH101/            → Introduction to Health and Wellness
/HLTH102/            → Communication for Health
/HSNS170/            → Health Science: Human Structure
/HSNS171/            → Human Structure Laboratory
/PSIO110/            → Introductory Human Physiology 1
/reference-cards/    → Quick reference cards & cheat sheets
/resources/          → Study guides, templates, session docs
/etsy-notes/         → Reformatted Etsy PDF content (scaffolding only)
```

## Study Loop

📖 **Learn** → 🎯 **Practice** → 📝 **Test** → ❌ **Review** → 🔄 **Retry**

Every topic follows this cycle. Content teaches first, then tests.
