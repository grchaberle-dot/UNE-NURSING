# Quality Improvement & Change Management

## 6 Dimensions of Quality
Patient-centred, Safe, Effective, Efficient, Equitable, Timely

## PDSA Cycle
Plan (define problem, SMART aim) → Do (implement, collect data) → Study (compare with baseline) → Act (adopt/adjust/abandon)

## Lewin's 3 Stages
Unfreeze → Change/Movement → Refreeze

## Kotter's 8 Steps
Create urgency → Build coalition → Develop vision → Communicate → Enable action → Short-term wins → Consolidate → Anchor in culture

## RCA Tools
- Fishbone/Ishikawa diagram
- Five Whys
- FMEA (proactive, before harm)
