# Pathophysiology Exam Technique

## Approach
1. Spot abnormalities
2. Match to condition
3. ABCDE priorities
4. Actual vs potential problems
5. Link interventions to pathophysiology

## Pharmacology Structure
Drug → Action → Why patient needs it

## Model Exam Structure
Assessment → Actual problems → Potential problems → Pathophysiology → Independent interventions → Collaborative interventions → Evaluation
