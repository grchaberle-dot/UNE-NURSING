# PSIO110/215 Gastrointestinal Physiology: Reference Notes

> **International medical school notes (structure and mnemonics reference only, not for app)**

## Stomach Anatomy
- **Body:** central reservoir, contains oxyntic (acid-forming) glands
- **Antrum:** distal, powerful peristaltic pump, gastrin secretion
- **Orad portion:** proximal 2/3 of body, accommodation and storage
- **Caudad portion:** distal 1/3 of body + antrum, propulsion and grinding

## Motor Functions
1. Storage (vagovagal reflex, capacity 0.8-1.5L)
2. Mixing (peristaltic waves every 15-20s)
3. Slow emptying (controlled chyme release)

## Key Cells
| Cell | Secretion |
|------|-----------|
| Chief (peptic) | Pepsinogen |
| Parietal (oxyntic) | HCl + intrinsic factor |
| G cells | Gastrin |
| ECL cells | Histamine |

## HCl Pathway
G cell -> gastrin -> ECL cell -> histamine -> H2 receptor -> H+/K+-ATPase -> HCl

## Pepsin
Optimal pH 1.8-3.5; inactive above pH 5; initiates 10-20% of protein digestion

## Phases of Secretion
Cephalic (~20%) -> Gastric (~70%) -> Intestinal (residual)

## Disorders
- H. pylori: urease-producing, urea breath test, CAP triple therapy
- NSAIDs: inhibit COX/PGE2, reduce mucosal protection
- Peptic ulcer: acid-pepsin injury exceeding defence
- Pernicious anaemia: IF deficiency -> B12 malabsorption

## Stress Response (GAS)
Alarm (adrenaline) -> Resistance (cortisol) -> Exhaustion
HPA: CRH -> ACTH -> cortisol
