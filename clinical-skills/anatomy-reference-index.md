# Anatomy Visual Reference Index

> ⚠️ US Source (SimpleNursing). Use for STRUCTURE and LABELLING only. Cross-reference with UNE PSIO110/PSIO120.

## Systems Covered
- Cardiac: chambers, valves, great vessels, conduction system
- Respiratory: upper tract, lower tract, full system, trachea, pharynx
- Nervous: brain regions, spinal cord, peripheral nerves
- Urinary: kidney cross-section, nephron, full urinary tract
- Reproductive: female (uterus, ovaries, tubes, breast), male (testes, prostate)
- Digestive: GI tract and accessory organs
- Musculoskeletal: muscle groups, skeletal system, joint anatomy
- Integumentary: skin layers, functions
- Lymphatic: nodes, vessels, spleen, thymus
- Sensory: eye and ear
- Tissues: epithelial types

These support the Anatomy ID game mode in the study app.
