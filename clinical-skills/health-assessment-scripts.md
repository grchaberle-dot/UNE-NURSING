# Health Assessment Clinical Scripts

## Universal Sequence
Hand hygiene → introduction → patient ID (name + DOB) → explain procedure → consent → privacy

## GI Assessment
Inspection (oral, abdomen size/shape/symmetry) → Auscultation (RLQ clockwise, 5-30 sounds/min) → Palpation (RLQ clockwise, 1cm deep)

## Cardiovascular Assessment
Inspect pulsations → Palpate pulses (radial, posterior tibial, cap refill <2sec) → Auscultate (aortic 2nd ICS R, pulmonic 2nd ICS L, tricuspid 5th ICS L, mitral 5th ICS mid-clav)

## Respiratory Assessment
Inspect (symmetry, accessory muscles, SpO2) → Palpate (rise/fall, air entry) → Auscultate (vesicular, bronchovesicular, bronchial)

## A-G Practical Exam
A: Airway, B: Breathing (RR 12-20, SpO2 95%), C: Circulation (pulse 60-100, BP 120/80), D: Disability (AVPU, GCS 15), E: Exposure, F: Fluids, G: Glucose (BSL 4-7mmol)
